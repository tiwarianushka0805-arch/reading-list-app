## Live Demo

**Deployed Application:** [Open Reading List App](https://reading-list-app-dun.vercel.app/)
## Features

- Add books with a title and reading status.
- Change status between Want to Read, Reading, and Finished.
- Filter books by reading status.
- Prevent duplicate book titles, ignoring capitalization and extra spaces.
- Limit book titles to 60 characters.
- Delete individual books.
- Display Total Books, Currently Reading, and Finished counts.
- Responsive interface for desktop and mobile devices.

## Technologies Used

- HTML
- CSS
- JavaScript
- GitHub
- Vercel

## Data Storage

Book data is stored in the browser, without a cloud database or user authentication.
